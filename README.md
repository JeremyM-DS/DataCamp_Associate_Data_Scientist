Ce dépôt GitHub regroupe l’ensemble des projets réalisés dans le cadre de ma formation Data Science sur DataCamp.
Il contient des exercices pratiques, des projets guidés et des projets autonomes couvrant un large éventail de compétences :

+ Manipulation de données (Pandas, NumPy)

+ Visualisation (Matplotlib, Seaborn)

+ Modélisation (régression, classification, arbres, boosting, SVM…)

+ Machine Learning avancé

+ Importation et gestion de données (CSV, TXT, HDF5…)

+ Prétraitement, feature engineering, validation croisée

+ Analyse de données réelles (Airbnb, LIGO, Indian Liver, Bikeshare, etc.)

Chaque projet est fourni sous forme de fichier ZIP, contenant :

+ Le notebook ou script Python

+ Les données nécessaires

+ Les consignes du projet

+ Les solutions ou pistes de travail

Ce dépôt sert de portfolio technique, montrant ma progression et mes compétences en data science.
