📘 Portfolio Data Science — Projets DataCamp

🇫🇷 Présentation
Ce dépôt GitHub regroupe l’ensemble des projets réalisés dans le cadre de ma formation Data Science sur DataCamp.
Il contient des exercices pratiques, des projets guidés et des projets autonomes couvrant un large éventail de compétences :

🔹 Manipulation de données
+ Nettoyage, fusion, transformation
+ Gestion des dates
+ Création de variables indicatrices
+ Feature engineering

🔹 Visualisation
+ Histogrammes, barplots, scatterplots
+ Courbes d’importance des variables
+ Visualisation de distributions

🔹 Machine Learning
+ Régression linéaire, Ridge, Lasso
+ Arbres de décision
+ Random Forest
+ AdaBoost
+ Gradient Boosting
+ Stochastic Gradient Boosting
+ Évaluation : MSE, RMSE, ROC AUC, accuracy

🔹 Importation de données
+ CSV avec Pandas
+ TXT avec gestionnaires de contexte
+ HDF5 avec h5py
+ Exploration de structures de fichiers complexes

Chaque projet est fourni sous forme de fichier ZIP, contenant :
- Le notebook ou script Python

Ce dépôt sert de portfolio technique, montrant ma progression et mes compétences en data science.
